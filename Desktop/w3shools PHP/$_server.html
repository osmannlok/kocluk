PHP `$_SERVER` Süper Globali

$_SERVER, başlıklar (headers), yollar (paths) ve betik (script) konumları hakkında bilgi tutan bir PHP süper global değişkenidir.

Örnek

Aşağıdaki örnek, $_SERVER içindeki bazı öğelerin nasıl kullanılacağını göstermektedir:

<?php
echo $_SERVER['PHP_SELF'];
echo "<br>";
echo $_SERVER['SERVER_NAME'];
echo "<br>";
echo $_SERVER['HTTP_HOST'];
echo "<br>";
echo $_SERVER['HTTP_REFERER'];
echo "<br>";
echo $_SERVER['HTTP_USER_AGENT'];
echo "<br>";
echo $_SERVER['SCRIPT_NAME'];
?>

$_SERVER İçindeki Önemli Öğeler

Aşağıdaki tabloda, $_SERVER içinde bulunabilecek en önemli öğeler listelenmektedir:

Öğe/Kod Açıklama (Türkçe)
$_SERVER['PHP_SELF'] Halen yürütülmekte olan betiğin dosya adını döndürür.
$_SERVER['GATEWAY_INTERFACE'] Sunucunun kullandığı Ortak Ağ Geçidi Arabirimi (CGI) sürümünü döndürür.
$_SERVER['SERVER_ADDR'] Ana bilgisayar sunucusunun IP adresini döndürür.
$_SERVER['SERVER_NAME'] Ana bilgisayar sunucusunun adını döndürür (örneğin, www.w3schools.com).
$_SERVER['SERVER_SOFTWARE'] Sunucu kimlik dizesini döndürür (örneğin, Apache/2.2.24).
$_SERVER['SERVER_PROTOCOL'] Bilgi protokolünün adını ve sürümünü döndürür (örneğin, HTTP/1.1).
$_SERVER['REQUEST_METHOD'] Sayfaya erişmek için kullanılan talep yöntemini döndürür (örneğin, POST veya GET).
$_SERVER['REQUEST_TIME'] Talebin başlangıcının zaman damgasını döndürür (örneğin, 1377687496).
$_SERVER['QUERY_STRING'] Sayfaya bir sorgu dizesi (query string) aracılığıyla erişilirse, bu sorgu dizesini döndürür.
$_SERVER['HTTP_ACCEPT'] Mevcut talepten Accept başlığını döndürür.
$_SERVER['HTTP_ACCEPT_CHARSET'] Mevcut talepten Accept-Charset başlığını döndürür (örneğin, utf-8,ISO-8859-1).
$_SERVER['HTTP_HOST'] Mevcut talepten Host başlığını döndürür.
$_SERVER['HTTP_REFERER'] Geçerli sayfanın tam URL'sini döndürür (tüm kullanıcı aracıları desteklemediği için güvenilir değildir).
$_SERVER['HTTPS'] Betiğe güvenli bir HTTP protokolü (HTTPS) üzerinden mi erişildiğini belirtir.
$_SERVER['REMOTE_ADDR'] Kullanıcının geçerli sayfayı görüntülediği IP adresini döndürür.
$_SERVER['REMOTE_HOST'] Kullanıcının geçerli sayfayı görüntülediği Ana bilgisayar adını (Host name) döndürür.
$_SERVER['REMOTE_PORT'] Kullanıcının makinesinde web sunucusuyla iletişim kurmak için kullanılan bağlantı noktasını (port) döndürür.
$_SERVER['SCRIPT_FILENAME'] Halen yürütülmekte olan betiğin mutlak yolunu (pathname) döndürür.
$_SERVER['SERVER_ADMIN'] Web sunucusu yapılandırma dosyasındaki SERVER_ADMIN yönergesine verilen değeri döndürür.
$_SERVER['SERVER_PORT'] Web sunucusunun iletişim için kullandığı sunucu makinesindeki bağlantı noktasını döndürür (örneğin, 80).
$_SERVER['SERVER_SIGNATURE'] Sunucu tarafından oluşturulan sayfalara eklenen sunucu sürümünü ve sanal ana bilgisayar adını döndürür.
$_SERVER['PATH_TRANSLATED'] Geçerli betiğe dosya sistemi tabanlı yolu döndürür.
$_SERVER['SCRIPT_NAME'] Geçerli betiğin yolunu döndürür.
$_SERVER['SCRIPT_URI'] Geçerli sayfanın URI'sini (Uniform Resource Identifier) döndürür.
