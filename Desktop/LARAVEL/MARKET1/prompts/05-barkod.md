# Görev 5: Barkod Yönetimi

## Kapsam

- Ürüne barkod ekleme
- Barkod düzenleme
- Barkod silme
- Barkodla ürün arama
- Barkod okutunca ürün bulma

## Kullanılacak Tablolar

- products
- product_barcodes

## Kurallar

- Barkod alanı unique olmalıdır.
- Bir ürüne birden fazla barkod eklenebilmelidir.
- Ana barkod belirlenebilmelidir.
- Barkodla arama API endpoint’i oluşturulmalıdır.

## Kabul Kriterleri

- Barkod ile ürün bulunabilmelidir.
- Aynı barkod ikinci kez eklenememelidir.
- Barkod okutunca doğru ürün dönmelidir.
