# Frontend & Tasarım Skilli

Projenin ön yüz geliştirme kuralları:
1. **Framework:** Bootstrap 5.3 CDN sürümleri kullanılacaktır. Tasarımlar tamamen duyarlı (Responsive / Mobil Uyumlu) olmalıdır.
2. **HTML / CSS:** Temiz, semantic HTML5 etiketleri kullanılacak. E-ticaret şablonuna uygun (ürün kartları, fiyat etiketleri, sepet tablosu, modern navbar) Bootstrap sınıfları tercih edilecektir.
3. **JavaScript (AJAX):** Sepete ekleme, sepetten ürün silme ve miktar güncelleme işlemleri sayfa yenilenmeden (Vanilla JavaScript Fetch API kullanılarak) asenkron (JSON tabanlı) gerçekleştirilecektir.
