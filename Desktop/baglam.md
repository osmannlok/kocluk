BAĞIMSIZ PROJE BAĞLAMI

“Gonca Lök | Öğrenci ve Kariyer Koçluğu” adlı kullanıcı girişli bir web uygulaması geliştiriyorum.

Teknoloji:
- Native PHP 8.2+ kullan.
- Laravel, CodeIgniter, Symfony veya başka PHP frameworkü kullanma.
- MySQL 8+ ve PDO prepared statement kullan.
- HTML5, CSS3, Bootstrap 5 ve Vanilla JavaScript kullan.
- React, Vue, Angular ve jQuery kullanma.
- Kullanılabilecek küçük kütüphaneler: Chart.js, FullCalendar, SortableJS, Flatpickr, SweetAlert2, Lucide Icons.
- Kod yapısı hafif MVC olmalı: Core, Controllers, Services, Repositories, Middleware, Views.
- PHP, CSS ve JavaScript dosyalarını ayır.
- Arayüz dili Türkçe; sınıf, fonksiyon, değişken ve dosya adları İngilizce olsun.
- Tüm SQL sorgularında PDO prepared statement kullan.
- Tüm kullanıcı girdilerini backend tarafında doğrula.
- HTML çıktılarında XSS önlemek için htmlspecialchars kullan.
- Durum değiştiren POST, PUT, PATCH ve DELETE işlemlerinde CSRF token kullan.
- Parolalar password_hash ve password_verify ile yönetilsin.
- Başarılı girişten sonra session_regenerate_id(true) uygula.
- Öğrenci yalnızca kendi verilerine erişebilsin.
- Koç yalnızca kendisine atanmış öğrencilere erişebilsin.
- Veli yalnızca izin verilen öğrenci özetlerini görebilsin.
- Koç özel notları öğrenci ve veli tarafından görülemesin.
- Uygulama ileride çoklu koç/kurum sistemine uygun organization_id yapısına sahip olsun.
- UI mobil öncelikli, sade, modern ve erişilebilir olsun.

ÇIKTI KURALLARI:
- Sadece istenen küçük görevi yap.
- İstenmeyen modülleri üretme veya değiştirme.
- Önce “Oluşturulacak/Güncellenecek Dosyalar” listesini ver.
- Sonra yalnızca gerekli dosyaların TAM içeriğini ver.
- Var olan bir dosyayı değiştiriyorsan dosyanın tamamını yeniden yaz.
- Placeholder, yarım kod veya “sonra tamamlanacak” tarzı kod bırakma.
- Kod çok uzarsa işi yeni dosyalara böl; başka modüllere geçme.
- En sonda en fazla 5 maddelik test/kurulum notu ver.
- İlgili mevcut dosyalar bu promptla birlikte yüklenmiş veya yapıştırılmıştır.
- Gerekli bir ön koşul dosya veya tablo yoksa tahmin etme; sadece eksik ön koşulu belirt.
